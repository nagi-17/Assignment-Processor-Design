# Taste

## Documentation

- Prefers README files to be short, concise "landing pages" rather than long documents; detailed content belongs in a separate document (e.g., a report), not the README. Confidence: 0.85
- Likes a landing-page README structure: centered hero image/logo + centered project title, a badge row, a one-line bold description, then brief sections (overview, architecture, key features, build/run, links), keeping the deep detail elsewhere. Confidence: 0.7
